# 밥줄 브랜드 이미지

- `bapjul-logo.svg`: 사용자가 제공한 `image 26.svg` 원본 (1254×1254).
- `bapjul-logo.png`: 위 SVG가 참조하는 내장 PNG를 재인코딩 없이 추출. 투명도/색상/픽셀을 변경하지 않았다. React Native `Image`에서 사용한다.
- `bapjul-wordmark.png`: Figma `YpZ1g2sdsGYg9MumKPywx3`, 로그인 프레임 `112:219`의 `image 5` (`113:199`)를 3× PNG로 내보낸 원본 (471×237; 프레임 밖 투명 여백 2px는 Figma 내보내기에서 제외됨). 내보내기용 설정은 다운로드 후 제거했다.

Figma에서 확인한 헤더 슬롯은 159×79, 로그인 기준 X=-2/Y=17. 앱은 기존 412→390 스케일을 적용하며 뒤로가기 행은 유지한다. 시작/권한/가입 완료 화면은 캐릭터와 워드마크 조합, 나머지 헤더는 워드마크를 쓴다. 전체 화면 캡처나 임의 글꼴로 대체하지 않는다.
