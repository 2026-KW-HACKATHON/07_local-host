# 앱 아이콘

사용자 제공 512×512 투명 PNG를 변경 없이 보관한다.

- search.png: 손님 식당 검색창.
- marketing.png: 손님 하단 제보 메뉴. 선택 시 검정, 비선택 시 흰색 tint.
- point.png: My 포인트 안내. 서버 연동 전에는 잔액/적립 성공을 임의로 표시하지 않는다.

`src/components/AppIcon.tsx`에서 비율을 유지해 렌더링한다. 집과 사람은 사용자 요청에 따라 React Native 도형으로 직접 구현했으며, 외부 아이콘 라이브러리를 사용하지 않는다. 밥줄 로고는 원본 제공 대기 상태다.
