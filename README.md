# 밥줄 프론트엔드

피그마 412 × 917 모바일 디자인을 기준으로 구현한 반응형 프론트입니다.

## 실행

Node.js가 설치된 환경에서 다음 명령을 실행합니다. 별도 패키지 설치는 필요하지 않습니다.

```sh
npm run dev
```

- 시작·권한 안내 화면: http://127.0.0.1:5173/onboarding.html
- 점주 식당 정보 입력: http://127.0.0.1:5173/

## 구현한 기능

- 시작 로고 표시 후 2.5초 뒤 위치 안내로 자동 전환. 새로고침 시 시작 화면부터 표시합니다.
- 위치·알림 안내창의 선택 버튼과 화면 전환. 선택은 UI 설정이며 실제 기기 권한 요청은 아직 연결하지 않았습니다.
- 네이버 검색을 새 탭으로 열고, 돌아와 지점명을 확정하는 입력 화면.
- 숫자 휠을 이용한 시작·마감 시간 선택.
- 휴무일 복수 선택 또는 연중무휴 설정.
- 식당 정보를 브라우저에 저장.

모바일에서는 화면 너비에 맞춰 크기를 조절하고, 넓은 화면에서는 412px 너비로 중앙 배치합니다.
전체 디자인 원본은 `밥줄 UI.svg`입니다.
